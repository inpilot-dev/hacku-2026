# Mandate identity

A rounded wallet with a negative-space M. The body uses a diagonal gradient
from Kumi orange (#ff922b), through Kip green (#26b873), to Stella pink (#f65fa7).
A subtle highlight suggests the wallet opening, without clasp decorations.

BrandLogo.tsx uses unique SVG mask and gradient IDs per instance.
mandate-mark.svg and the icons share the same geometry. The wordmark uses
locally hosted Manrope at weight 750, scoped to the logo. See OFL-Manrope.txt
for the SIL Open Font License.
