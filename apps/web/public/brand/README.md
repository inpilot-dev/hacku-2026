# Mandate identity

A rounded purse with a negative-space M and three clasp accents: Kumi orange
(#ff922b), Kip green (#26b873), and Stella pink (#f65fa7).

BrandLogo.tsx uses currentColor for the purse, keeping it legible in both themes,
and a unique SVG mask per instance. mandate-mark.svg and the icons share the
same geometry. The wordmark uses locally hosted Manrope at weight 750, scoped
to the logo. See OFL-Manrope.txt for the SIL Open Font License.
